skills present?\n  - Tech stack compatibility\n\n- **Salary Alignment** (25%)\n  - Within target range?\n  - Market rate?\n  - Growth potential?\n\n- **Company** (20%)\n  - Reputation (YC, public, well-funded?)\n  - Size (startup, mid-market, enterprise?)\n  - Industry/sector alignment\n\n- **Growth Opportunity** (10%)\n  - Learning potential\n  - Career advancement\n  - Team quality (implied from description)\n\n- **Location/Remote** (5%)\n  - Remote?\n  - Location preference match?\n  - Timezone alignment?\n\n### Score Interpretation\n\n- **8-10**: Excellent match (SUBMIT)\n  - \"This job is perfect for you\"\n  - High success likelihood\n  - Strong skill match\n\n- **6-7**: Good match (CONSIDER)\n  - \"Decent opportunity but not ideal\"\n  - Some tradeoffs\n  - Worth exploring\n\n- **4-5**: Moderate match (RISKY)\n  - \"You could do this but...\"\n  - Significant gaps\n  - Low priority\n\n- **1-3**: Poor match (SKIP)\n  - \"Not a good fit\"\n  - Major concerns\n  - Waste of time\n\n---\n\n## 📈 Dashboard Metrics Explained\n\n### Key Metrics\n\n1. **Jobs Discovered**\n   - Total unique job listings synced\n   - From all 5 sources\n   - New jobs added daily\n\n2.
